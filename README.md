# ML-AI

Machine learning and AI projects, from algorithms built from first principles to modern deep learning and LLM tooling.

## About this hub

This repository is an index. Each project lives in its own repository with its own code, tests, environment and results. I start from the fundamentals, implementing core algorithms by hand and checking them against reference libraries, then build up to PyTorch models and LangChain applications.

## Projects

| Project | What it does | Stack | Status |
|---|---|---|---|
| [ml-from-scratch](https://github.com/AzeemDgreat/ml-from-scratch) | Linear and logistic regression, KNN, decision tree and random forest implemented in NumPy and verified against scikit-learn | NumPy, pytest | Ready |
| pytorch-fundamentals | Tensors, autograd and training loops, then MLP and CNN models built with `nn.Module` | PyTorch | Planned |
| langchain-fundamentals | Prompts and chains, then retrieval-augmented generation (RAG) and tool-using agents | LangChain | Planned |
